# 歌词获取

每家播放器独立获取歌曲资料和进度，只读取当前播放器的本地歌词缓存，以及用户明确指定的歌词目录；不会把另外安装的客户端当成备用。QQ 使用自身 QRC，酷狗使用自身 KRC，汽水使用自身媒体缓存，网易云使用自身资料库中的歌曲 ID 及歌词。切换客户端会清空上一家的索引，并按当前来源重新读取目录。

当前播放器的本地路径与 AMLL 公共歌词库并行查找，网易云、QQ、汽水还可请求各自公开歌词接口；第一份有效歌词返回。网络来源不要求安装其他音乐软件。某一路未匹配或出错不会取消其他路径；全部失败后保留当前来源及公共网络路径的具体原因。切歌、切播放器或关闭歌词会取消请求并停止本地查找。

## 本地文件

按当前客户端扫描对应的常见用户数据目录，跳过其他客户端目录；无法归属的普通 LRC、TTML、JSON 只在用户指定目录中读取。支持 QRC、KRC、LRC、YRC、TTML 和歌词目录中的部分 JSON 缓存。QRC/KRC 解密后使用正文元数据或文件名匹配，TTML 支持 AMLL 的 musicName/artists/album 元数据。JSON 支持歌手数组、专辑对象；逐字字段损坏时继续尝试 LRC。

歌名与歌手必须匹配，多歌手按集合比较；已知时长允许 4 秒差异。同分的有效本地文件正文不一致时拒绝猜版本；损坏候选不阻止其他有效候选。扩展名、播放器数据库结构及没有歌曲身份信息的缓存仍有兼容边界。

已发现目录每 30 秒检查直接文件，每 5 分钟补查常见目录的新子目录。改变个人目录会触发定向扫描，“重新查找”启动完整扫描；已记忆磁盘根目录不会变成周期性全盘递归扫描。

酷狗额外读取 `%APPDATA%/KuGou8/KuGou.ini` 中的 LyricPath、DownloadPath，发现自定义盘符中的歌词目录。识别 `歌手 - 歌名-32位hash-数字ID-8位标志.krc` 缓存名，精确去除缓存后缀，并以其中的歌手、歌名匹配播放器；这可处理正文标签为空、正文附带影视插曲说明、正文省略合作歌手等情况，仍保留文件名中的 Live 等版本信息。其他文件继续采用正文元数据，缺失字段才从普通文件名补齐。文件名缓存 hash 不当作音频 hash。

## 汽水媒体缓存

普通本地文件未命中时，只读检查 `%APPDATA%/SodaMusic/LunaCacheV2/entries.db` 等位置。使用带边界检查的 lmdb-js 格式 2 页面读取和 msgpackr record 解码，直接提取 mediaDetail 的歌曲资料与歌词正文，保留 KRC 逐字时间。不会加载客户端代码或 DLL，不读取音频 bin 文件，不创建播放器锁文件。

歌名、歌手、时长必须通过相同身份检查，专辑精确匹配优先；跳过试听、隐藏歌词、曲目标识冲突和无效时间轴。同分的不同歌曲 ID 或不同正文保留版本歧义。读取上限 64 MB、单条 2 MB、10,000 条记录，限制遍历深度和节点数量，拒绝循环页与越界引用；读取中缓存发生更新则重试。

当前支持已验证的 LunaCacheV2 格式；客户端升级变更格式时会报告该路缓存不支持，其他歌词途径继续查找。QQ、网易云、酷狗和汽水是当前四个音源；酷我已移除，历史选择迁移到自动识别。

## 网易云本地歌曲 ID

Windows 从 `%LOCALAPPDATA%/Netease/CloudMusic/Library/webdb.dat` 等已知位置，只读查询 dbTrack、historyTracks、offlineTrack 的歌曲资料。不读取账号、Cookie 或请求记录，不改动播放器文件。

先严格匹配歌名、歌手、专辑优先级与时长，只有最佳候选歌曲 ID 唯一时才继续。按 ID 检查 Lyric、Cache/Lyric、webdata/lyric 中的本地正文和 SoundSpectra 自有缓存；缺失时使用网易云公开歌词接口。优先采用 YRC 逐字歌词，支持 LRC 回退，无需播放器正在运行。资料库未收录或版本不唯一的歌曲继续交给其他路径。

网易云缓存最多 64 份、每份最多 2 MB，7 天内直接使用，过期时重新获取；网络失败时可使用经身份及时间验证的旧缓存。新歌词返回不等待磁盘写入。

## QQ、汽水免登录网络补充

只请求当前播放器对应的公开曲库，不读取客户端登录态或 Cookie。QQ 从公开歌曲建议中按歌名与歌手筛选，最多核验四个候选的歌曲详情及 MID，再请求对应 LRC；网络路径目前提供逐行时间，本地 QRC 继续保留逐字时间。汽水从公开曲库搜索当前歌名与歌手，按歌曲 ID 再次核验详情，仅取当前歌曲根级歌词字段中的 KRC，保留逐字时间；忽略推荐列表及隐藏歌词。

两路均要求歌名、歌手集合和有效时长匹配，已知播放时长允许 4 秒差异，专辑一致优先；最佳候选包含不同歌曲 ID 时拒绝猜测。搜索服务只返回有限候选，未找到或无法确定版本时继续依赖本地与 AMLL。每次请求上限 6 秒，整条平台路径最多 18 秒，响应上限 2 MB；换歌或其他路径先返回时丢弃请求并关闭未完成的响应。

SoundSpectra 自有平台缓存按 QQ／汽水分别标记，读取时重新验证歌曲身份、歌词时间、平台及歌曲键；共保留最多 64 份，每份最多 2 MB。7 天内直接使用，过期重新获取，网络不可用时允许使用已验证的旧缓存。返回歌词不等待缓存写入。此补充仅解决歌词正文获取，不提供外部音乐客户端缺失的播放进度。

真实服务验证：`cargo test --lib lyrics::platform::tests::public_ -- --ignored --nocapture`。只发送公开搜索、歌曲详情与歌词请求，不需要安装播放器或登录，不控制播放。

## 网易云和汽水的歌曲信息入口

优先读取系统媒体会话，缺失时由独立的只读无障碍线程补充歌曲资料。网易云使用当前窗口标题校验底栏，拒绝上一首残留的底栏信息；本机 3.1.42 的“设置 → 系统 → 开启 SMTC”可恢复歌曲资料和播放状态，但未提供时间轴。汽水 3.7 的底栏叶节点提供歌名、歌手和秒级时间，不能使用可能滞后的组摘要。缺少媒体播放状态时，位置真实推进才判定播放；停止变化、倒退拖动、换歌或进程变化会重置推算。过期超过 2.5 秒的采样不再用于歌词时钟。该兼容入口不调用播放控件，不虚构 SMTC 控制能力。

## 网易云本地播放事件时钟

网易云缺少系统及无障碍时间轴时，只读跟踪 `%LOCALAPPDATA%/NetEase/CloudMusic/cloudmusic.elog`。解码并提取当前进程的歌曲资料、原生资源加载、播放／暂停、绝对拖动位置及缓冲事件，以 Windows 单调时钟重建当前位置；窗口最小化时同样可读。歌曲请求本身不能开始计时，必须有同一歌曲的加载完成及原生播放状态；暂停、缓冲和重新加载期间停止推进，拖动按实际位置重新校准。

首次读取最多回放日志末尾 4 MB，因此在歌曲播放中途打开 SoundSpectra 也能恢复已有的有效时钟。进程创建时刻、当前 Windows 启动后的时间范围、歌曲 ID 和每次播放实例共同过滤旧记录；系统媒体会话提供歌名、歌手、时长或状态时必须一致。日志轮换、截断、损坏、倒序事件和无法确认的播放实例会使旧锚点失效。仅有客户端恢复记录而缺少可验证的开始或绝对位置时，继续等待有效事件，不从零猜进度。

日志每轮增量读取，成功观察后的有效期为 2.5 秒；读取中断超过 4 秒（包括挂起恢复）会丢弃旧锚点，等待新的有效位置。若客户端升级改变日志格式、关闭日志或日志尾部已没有开始记录，这条兼容路径可能暂不可用。音乐卡片和歌词共用该时钟；预览诊断标为“网易云本地播放事件同步”。不修改网易云文件、登录态或启动参数，不调用播放控件，不保存解码日志或资源地址。

只读实机验证：设置 `SOUNDSPECTRA_TEST_NETEASE_PID` 为正在播放的网易云主进程 PID，运行 `cargo test --lib now_playing::tests::installed_netease_event_clock_advances_without_playback_controls -- --ignored --nocapture`。核验独立 SMTC 歌曲资料、有效总时长和两秒连续推进；暂停、缓冲、拖动、重复播放、旧进程过滤及日志轮换由固定事件测试覆盖。

## 酷狗播放进度兼容

部分酷狗 20 客户端的 SMTC 会话提供歌名与播放状态，但 StartTime、EndTime、Position、LastUpdatedTime 全为 0。歌词读取成功并不代表已经取得同步时钟。

系统时间轴缺失时，Windows 适配器只读 KuGou.ini 的 LastPlayingSongHash、LastPlayingTitleName、LastPlayingSongPos。先匹配当前会话的歌手与歌名，再等待本进程观察到歌曲位置发生真实变化的新写入，使用该位置及写入时刻校准时钟。不会从打开应用或切歌时刻开始猜进度；配置的无关写入不会延长锚点有效期。当前实测约 30 秒更新一次，首次启用、切歌或播放状态变化后需要等待新记录，拖动后可能延迟校准。锚点 35 秒后失效，进程、歌曲标识或播放状态变化时重置。

歌词可以使用已知位置而无总时长的备用时钟，音乐卡片仍需要真实总时长才显示进度条。KRC 正文 hash 与当前音频 hash 相同时提高匹配优先级；不同 hash 可能来自不同音质或歌词来源，继续按歌曲资料匹配，同分不同正文仍拒绝猜版本。预览标明备用进度，桌面不显示这段说明。

本机只读验证：`cargo test --lib now_playing::tests::installed_kugou_checkpoint_advances_without_playback_controls -- --ignored --nocapture`。要求酷狗保持播放，最多等 55 秒观察新写入，不切歌、不暂停、不调整播放位置。

## 缓存与刷新

内存缓存同时校验歌曲信息、时长、播放器来源、进程、媒体会话、曲目标识、个人目录和索引代次，最长 30 秒。显式刷新不复用已完成结果，相同身份及索引代次的进行中请求合并。展示键保留歌名/歌手/专辑，避免改变现有歌词渲染协议。

## 验证

常规回归：`cargo test --lib lyrics::`（在 src-tauri 目录）。包含损坏文件回退、版本歧义、多歌手、TTML 索引、加密 KRC、网易云 SQLite 结构、歌曲 ID 请求、逐字时间、离线缓存、错误保留与取消。

本机网易云与真实服务只读验证：`cargo test --lib lyrics::netease::tests::installed_client_resolves_and_fetches_without_modifying_player_files -- --ignored --nocapture`。需要已安装客户端资料库且其中有歌曲记录，以及网络可用；测试不控制播放，缓存写入测试临时目录，验证前后播放器数据库内容一致。

酷狗真实文件：`cargo test --lib lyrics::discovery::tests::installed_kugou_lyrics_are_discovered_and_decoded -- --ignored --nocapture`。汽水真实缓存：`cargo test --lib lyrics::soda::tests::installed_cache_resolves_word_timed_lyrics_without_modifying_player_files -- --ignored --nocapture`。均只读本机已有歌词，不改变播放。
