# 歌词与动态文字

在「歌词」中启用歌词动效。无需手动填写缓存目录。

## 获取与缓存

联网查询和本地缓存读取同时开始，首个有效、非空的歌词结果胜出；错误和空结果不会中止另一侧。胜出后丢弃未完成的异步 HTTP 请求和响应体，通过停止标志终止进一步本地读取。同曲请求共享正在进行的查询，已有有效结果会复用，切歌会取消旧请求。

在线来源为网易云和 QQ。查询使用当前歌曲标题、歌手，并结合版本、时长等信息匹配；不上传本地文件或账号 Cookie。跨曲库查询可服务于菜单中的五类播放器，但私有歌词、服务不可用或版本匹配失败时不会编造内容。

首次目录发现先查常见缓存位置，必要时才扫描本地固定磁盘。发现的末级目录以原子方式写入配置旁的 `lyric-locations.json`。后续启动只索引已保存目录的直接文件，每 30 秒刷新，不定时全盘重扫。

失效或离线目录仍然保留；恢复及播放器切换时有限检查已知位置。缓存迁移后，可在「位置与同步 → 重新查找歌词目录」主动重新发现。损坏的位置记录先备份再替换，不因此自动触发全盘扫描。

解析支持 QRC、KRC、YRC、UTF-8 / UTF-16 LRC 及识别的 JSON 封装，只读取、不修改播放器缓存。

## 三种编排

| 名称 | 表现 | 保存 ID |
| --- | --- | --- |
| 文字漫游 | 对向短句、呼吸留白和缓慢镜头移动 | `depth` |
| 错落排版 | 阶梯式断句、字号差异与倾斜基线 | `stage` |
| 弧形流转 | 字符沿动态弧线排布与游移 | `stardust` |

渲染器由项目实现，使用系统衬线字体和歌词时间戳；运动由当前歌词时间直接计算，暂停和跳转不会累积漂移。减少动态效果时保留时序高亮，关闭移动。

## 位置与外观

- 在普通或放大预览中拖动歌词，右下角缩放；方向键微调，Escape 取消当前手势，松开提交位置。
- 歌词位置独立于灯效区域；桌面仍保持鼠标穿透。
- 「展开歌词舞台」恢复较大的舞台范围；切换编排时兼容升级未修改的旧默认范围，自定义位置仍可编辑。
- 字号可调，背景强度为 0–100%，默认 30%；0 为完全透明，舞台边缘渐隐。
- 同步偏移为 ±10 秒，正值让歌词提前。
- 断句逗号、句号等参与编排与计时，但不绘制；保留「合：」等歌手标签和撇号、小数点、英文缩写等语义符号。原歌词文件保持原样。

## 播放器与边界

音源菜单提供自动识别、QQ 音乐、网易云音乐、酷狗音乐、酷我音乐、汽水音乐。退休的播放器选项回退到自动识别。

播放同步依赖被捕获播放器的 Windows 媒体会话和有效时间线。暂停、跳转与切歌均跟随该会话；没有有效时间线时界面说明无法同步，桌面不会猜测进度。浏览器的原创示例歌词始终标记为模拟展示，不替代缺失的真实歌词。

## 验证

```powershell
npx playwright test tests/lyrics.spec.ts tests/audio-sources.spec.ts
node scripts/desktop.mjs --cargo test --manifest-path src-tauri/Cargo.toml --lib lyrics::tests
```

开发服务运行时，`node scripts/capture-lyric-compositions.mjs` 录制三种编排的 21 秒原创示例。

原生忽略测试 `local_cache_decodes_without_writing` 可用 `SOUNDSPECTRA_LYRIC_TEST_DIR` 指定真实缓存目录，检查 20 个样本而不向仓库复制歌词。忽略测试 `public_lyric_service` 用于实际在线服务检查，外部服务状态不属于离线回归结果。
