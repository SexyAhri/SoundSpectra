范围：音乐库、播放控制、灯效编辑、桌面布置、歌词、卡片、壁纸、拾光绳及共用控件。
沿用现有撤销、保存、Provider、场景收藏与 Native 播放逻辑。此次不调整发布版本。

## 检查原则

已有功能先核对再补齐；不创建第二套保存或播放状态。布局与功能使用真实数据，
不将缓存标记为离线授权；平台歌单与收藏仅提供读取。


## 使用与存储约定

- 属性栏默认 380 px，支持 300–560 px，受窗口可用宽度约束。拖动分隔线或使用左右方向键调整，双击恢复默认宽度；收起状态和宽度保存在本机。
- 歌词设置复用灯效的三栏样式，分为「动效 / 外观 / 同步与位置」；开关与状态保留在顶部，桌面宽度下仅当前栏的内容独立滚动。当前栏在本机记忆，切栏不修改实际歌词参数，切栏后自动关闭样式选择面板。
- 面板展开项和滚动位置按模块、设置页和编辑区域保存在本次会话；拾光绳分类、歌曲密度和停靠偏好保存在本机。音乐库的账号隔离浏览记录仍由原 SQLite 接口管理。
- 位置锁定只约束预览中的拖动、缩放、方向键和右键位置操作，属性栏仍可精确调整；不改变桌面输出或运行时的互动权限。隐藏对象仍可通过列表选择和解锁。
- 参数的数值按钮支持精确输入，Enter 提交、Escape 取消并返回焦点，数值按步长和边界规范化。提供默认值的参数恢复默认值，其他参数恢复进入该设置时的值；歌词、卡片与灯效保留分组重置和原撤销机制。
- 灯效候选只运行一个低帧率演示画布，焦点或悬浮仅预览，点击才应用；减少动态效果时使用静态图片。歌词预览优先选择当前演唱句，卡片使用当前歌曲信息。
- 宽屏固定阈值为 1200 px。歌词与队列均覆盖在列表右侧，不参与文档流；固定后点外部保持打开，取消固定后点外部关闭。Escape 和关闭按钮均可收起。

歌单标题与搜索栏合并为紧凑工具区；歌曲表格去掉外框和逐行横线，保留表头、悬浮、选中与当前播放层次。宽屏行操作居中且预留空间，窄屏保留紧凑布局。
