# 音乐库（1.1.14）

音乐库沿用现有工作台。Native Provider 管理认证和远程数据，共用播放器管理队列、缓存和状态；新增平台实现 `model.rs` 的 Provider 并注册登录流程及能力，不需要复制界面或播放引擎。

## 工作台交互

歌单标题与搜索并排显示，窄屏自动换行；搜索框复用公共组件，仅外层显示聚焦状态。歌曲表格去除外框和逐行分隔线，使用轻量悬浮、选中和当前播放状态，并保留舒适与紧凑密度。宽屏歌曲行中部预留操作区，悬浮或聚焦时显示播放、下一首与更多菜单，避免遮住歌名、专辑和时长；窄屏保留紧凑操作。搜索栏将范围与歌单分类分开：可选择平台曲库、已同步歌曲，或返回上次浏览的当前歌单；平台搜索按回车或点击搜索执行，本地筛选即时生效。最近播放、我喜欢、创建和收藏歌单保留独立分类。尚未同步的数据单独提示，匹配数与已加载数量分开显示。

歌曲行单击选中，双击或 Enter 播放；悬浮或聚焦后显示播放、下一首和更多操作，右键菜单提供相同操作。舒适与紧凑密度保存在本机，大歌单仍按需渲染。账号刷新和退出位于头像菜单。封面氛围色从已缓存图片取样，取样失败沿用主题色。

其他编辑页显示迷你播放栏，与音乐库共用同一份播放订阅；点击封面返回音乐库。歌词和队列始终覆盖在列表右侧，不挤压列表宽度或改变滚动位置；宽屏「固定 / 已固定」按钮控制点击外部时是否保持打开，固定状态不改变面板位置。窄屏和迷你栏支持点击外部关闭，所有面板均可用 Escape 或关闭按钮收起。歌词面板将歌名与刷新按钮并排，歌手和歌词来源合并为一行，长文本省略并可悬浮查看。设置保持临时抽屉。音乐库宽屏播放栏收紧至约 80 px，保留音质、进度和全部控制；底部的桌面输出与渲染性能收进「桌面与性能」。

提示统一延迟显示，离开控件收起，支持键盘焦点与窗口边缘避让。下载、缓冲、播放与跳转继续共用一条进度条。

播放滑块和填充在原生进度反馈之间同步平滑推进；暂停、缓冲、跳转中或反馈超过 900 毫秒未前进时停止推算。拖动与切歌直接定位，不经过增长动画；跳转命令等待确认时短暂保持目标位置，避免滑块弹回旧进度。下载与缓冲填充使用宽度过渡，减少动态效果时直接显示已确认值。

## 平台与登录

登录页提供获取 / 刷新二维码、取消和直接打开官方授权；按钮执行时显示进度并防止重复提交，恢复登录及账号验证期间仍可取消。授权会话过期、出错或窗口丢失时重新创建受监听的会话；QQ / 网易的官方窗口关闭后隐藏，可再次打开。旧登录的迟到状态不能覆盖取消或新平台登录。重新扫码时优先显示登录页，确认成功后自动进入歌单，取消则返回原账号。登录期间隐藏空播放器；官方安全验证需要用户完成，酷狗完成验证后按提示刷新二维码。

未登录时展示统一的「连接你的音乐」页：左侧选择平台，右侧显示该平台的二维码、扫码步骤和登录状态；窄窗口自动调整布局并在内容区内滚动。QQ 音乐、网易云音乐和酷狗音乐开放连接。平台可用性由 Native 的 `qr-login` 能力决定；登录命令携带平台标识，未实现的平台在 Native 层拒绝。切换可用平台前取消旧登录，取消失败保留当前平台；恢复登录期间禁用重复操作，并保留恢复的平台。

QQ 音乐独立实现账号、会员、已创建 / 已收藏歌单读取、全部分页、全站搜索、音质授权、封面及歌词。全站搜索使用 QQ 官方 `music.search.SearchCgiService / DoSearchForQQMusicDesktop`，携带当前登录会话；歌曲点播另行取得当前账号的播放授权。搜索为可选能力，界面依据 Provider capabilities 显示。QQ、网易云、酷狗三个平台均不提供云端喜欢 / 取消喜欢、歌单增删改或收藏写入；登录、搜索、歌单读取、播放与本地队列按各平台现有能力保留。

QQ 与网易云扫码页在隔离官方 WebView 内运行官方轮询与授权交换，酷狗由原生端实现官网二维码流程，工作台仅显示二维码和状态；额外验证由用户打开官方窗口完成。远程页面无应用 IPC 权限。Windows 凭据按平台分别保存在配置目录 `music/qq-session.dpapi`、`music/netease-session.dpapi`、`music/kugou-session.dpapi`，以当前用户 DPAPI 加密；官方 WebView 分别使用 `music/qq-webview`、`music/netease-webview`、`music/kugou-webview`。`active-provider` 只保存固定平台名，旧版 QQ 凭据兼容恢复。Cookie、签名音频地址不进入前端、SQLite、场景、导出与诊断。macOS 会话仅保留在进程内，尚无跨启动凭据恢复。

网易云 Provider 自主实现账号校验、会员、已创建 / 已收藏歌单读取、按完整 `trackIds` 补曲目详情、平台搜索、播放取址、歌词和封面。当前使用固定官方 `/api/` GET 路径，不依赖 Node API 服务，也未实现通用 weapi/eapi/xeapi。音质标识覆盖标准、较高、极高、无损、Hi-Res、高清臻音、沉浸环绕、超清母带、杜比全景声、臻音全景声；实际使用哪档由每曲完整授权和 MP3 / FLAC 解码支持决定，不承诺全部空间格式可播放。普通自动选档不显示降级，资源播放或解码失败后的切换才显示降级；带试听标记的地址不作为完整曲播放。当前会话的账号、会员和恢复已验证，私有歌库完整性与高级音质覆盖仍需真实账号验收。API 请求间隔至少 500ms，风控 / 限流暂停本地请求预算，后台同步遇认证 / 风控 / 限流停止。接口与音质说明见 [NETEASE.md](NETEASE.md)。

酷狗开放官网二维码、账号、搜索、已创建及已收藏歌单的读取、我喜欢、封面、歌词、标准 MP3 播放，复用公共播放器、队列与后台索引。通过 Rust 直连 H5 cloudlist 与 tracker 网关。实际账号歌单及 186 秒完整标准 MP3 已验证，原生渐进传输和整首解码实测通过。逐曲核对服务端授权、版本、完整时长及真实音频，不把官网试听地址用于完整播放。高品质、无损和歌单本身的新建/删除/改名未开放；完整桌面扫码与重启恢复仍待实机验收。独立实现范围与验证记录见 [KUGOU.md](KUGOU.md)。

## 播放与错误恢复

播放、操作、歌单加载和歌词预览错误统一显示顶部短暂 message，默认 5 秒后消失，也可手动关闭；悬停或聚焦时暂停计时。相同错误不会因状态轮询反复弹出，新的播放失败可重新提示；按错误类型提供重试或重新扫码。

`playback.rs` 是播放状态的唯一持有者；前端命令按接收顺序进入 Native，授权与音频请求在可取消后台任务内执行。加载期间可暂停、停止和连续上下首；具体歌曲点选以最后目标为准。过期歌曲代次和命令版本的响应无效，暂停意图不会被下载完成覆盖。后台 `music-player` 只持有 HTMLAudio 和受限的本地播放命令，切换工作台页面不影响音频。

自动选取账号实际可用的最高音质：超级会员候选依次包含臻品母带、臻品音质、臻品全景声、Hi-Res、SQ、HQ、标准 MP3、AAC；绿钻从 Hi-Res 开始，普通或过期账号从 HQ 开始。会员信息未知时仍由服务端授权决定；成长等级不等同于歌曲权限。资源不可用或解码失败逐级降级，不以试听绕过授权。FLAC 规格取自 STREAMINFO，MP3 / AAC 码率按文件长度和时长估算；实际音质显示在播放栏。

校验首段后立即播放，其余内容后台下载。Native 仅向隐藏播放器暴露带随机凭证的本机环回地址；校验 Host、路径和 Range，限制连接数，远距离跳转可另取服务器分段。无 Content-Length 的兼容路径有完整下载等待。单曲最多 256 MiB；半成品不落盘，切歌与停止取消旧请求。播放、下载、实际缓冲范围和跳转动画叠在同一进度条，下载完成隐藏纹理，减少动态效果时停用动画。200 毫秒淡出、250 毫秒淡入独立于用户音量，归零立即静音。

网络授权失败重试两次，等待一秒、三秒，可取消。传输中断恢复最多两次，持续成功播放后重置预算。登录失效停止自动重试并提供扫码入口；自动续播遇资源或解码不可用最多连续跳过三首。断网保留暂停现场，联网仅在目标及命令版本仍匹配时恢复；休眠间隔检测和输出设备错误会尝试从原进度恢复。设备兼容性由系统和 WebView 音频后端决定。

音频引擎读取状态和上报进度时设置五秒响应超时，单次响应丢失不会永久阻塞后续同步，迟到的旧响应也不会覆盖新状态。音频准备及缓冲期间，播放按钮显示加载指示，实际播放由音频引擎反馈确认。

当前歌曲完整下载后才预取下一候选，最多 4 MiB 内存，不落缓存、不续期、不计入历史。随机候选提前确定，切歌只消费一次；更换队列、模式、账号或加载目标时取消旧预取。真正播放仍重新确认授权。系统媒体键、耳机与系统面板经 MediaSession 接入受限 Native 命令；外部音源激活时释放内置媒体状态。

## 持久化、搜索与队列

`music/library.sqlite` 按账号哈希隔离歌曲索引、歌单、播放现场、最近记录、偏好、浏览现场与歌词偏移。不保存 Cookie 或播放地址；保留 Native 点播所需歌曲标识。数据库迁移先生成一致备份，再在事务中升级，较新格式拒绝降级读取。

现场包含稳定队列条目标识、曲目、位置、音量、静音与模式。播放进度最多每五秒保存，暂停和正常退出立即保存；重启恢复后暂停等待操作。最近播放保留 1000 首去重记录，独立于音频清理。元数据后台逐页同步，分页按服务端跨度计算，被过滤的歌曲也占跨度；缺页不能标记同步完成。尚未同步的数据不在本地搜索结果中，可刷新读取更新的索引。

歌曲右键菜单提供立即播放、下一首播放、加入队列和封面重试。按歌名、歌手、专辑、时长排序，保留完整版本标题；点播沿用当前显示顺序。队列可拖动排序、用上下移按钮操作、多选移除及清除当前之前的歌曲，稳定条目标识保持正在播放的音频与进度；当前歌曲受保护。歌单、筛选、排序和滚动位置按账号恢复，长列表按需渲染；轮询使用队列版本，未变化时不重复克隆或发送完整队列。

## 缓存与响度

歌曲与歌词独立获取。歌曲只保留播放器本次使用的内存缓冲，不写入完整音频文件，不持久化签名播放地址；保存歌曲标识和播放现场，实际播放时重新取得当前账号的授权链接。边下边播、已下载片段读取和远距离 Range 跳转保持可用。切歌、停止、退出或取消请求后释放缓冲，下一首预取仍最多 4 MiB 内存。启动、定时维护和打开缓存设置时移除原有 `audio.bin` 及未完成的音频临时文件，保留有效歌词与已有响度测量；清理磁盘文件不会破坏播放器持有的内存数据。

歌词和小型响度测量保存在 `music/cache/track-*`，默认总容量 32 MiB，可选 8 / 16 / 32 / 64 MiB，最多 4096 曲；歌词单条 2 MiB，在线播放单曲仍限制 256 MiB。身份由平台、歌曲 ID、标题、歌手、专辑和时长决定。连续七天未播放移除歌词和测量，超限按最久未播放清理；启动、每小时、写入及容量调整时维护。只有实际播放续期，预取、查看和刷新歌词不续期。旧 GiB 容量偏好自动迁移为默认 32 MiB，保留响度开关。

设置显示歌词和测量索引的占用，封面独立位于 `music/covers`，上限 128 MiB，七天未访问清理，失败可右键重试。手动清理歌词时，正在使用的资源释放后补清理，清理前发出的迟到请求不能重新写回。缓存失败不阻止在线播放；刷新歌词失败保留有效版本。若旧音频文件未能自动释放，设置保留清理旧音频入口。

歌曲响度平衡默认关闭。开启后，完整下载的内存缓冲共享给单个后台工作线程，最多再排队一首，取消的播放会终止分析；不为分析保存音频副本到磁盘。Symphonia 逐包解码、ebur128 测量，避免完整 PCM 常驻内存。仅将音质、长度、内容校验值和响度等少量元数据写入 `entry.json` / `loudness.json`。以 −18 LUFS 为目标，仅衰减过响歌曲；完整音频准备好并通过内容校验后复用测量，未分析、静音或无法解码时保持原音量。改变开关在下次播放使用，依赖许可见 `THIRD_PARTY_NOTICES.md` 和 `licenses/`。

## 歌词与定时

逐曲偏移保存在 SQLite，范围前后十秒，每次 0.5 秒，正值延后。Native 只给副本应用一次逐曲偏移，全局偏移由公共显示规则另行合成；音乐库与桌面歌词一致，点击跳转使用相同偏移规则。歌词以固定行高平滑滚动，通过缩放和淡入淡出强调当前句；补齐两次播放位置更新之间的句子切换，并在反馈过期时停止外推。手动滚动后保持浏览状态，底部悬浮的“回到当前句”恢复跟随且不挤压歌词正文；首尾也可居中，支持系统减少动态效果。制作信息不作为演唱歌词高亮。

睡眠设置支持 15 / 30 / 60 分钟及本曲结束暂停，经过现有淡出停止；不持久化睡眠倒计时。停止、清空和模式切换保持用户音量偏好。

## 诊断与验证

本地阶段日志保留最多 512 条，仅记录固定阶段、歌曲代次和结构化错误类别，不接受凭据或任意远程地址。可在音乐库设置导出 JSON；SQLite 写入失败也记录明确的存储类别。

自动检查入口为 `npm run check:full`，包含依赖、版本、发布脚本、前端、完整浏览器回归、Rustfmt、Rust 全测试与本机原生构建。音乐专项测试覆盖取消与最后目标、暂停交错、随机预取、账号隔离和恢复、迁移及缺页、历史上限、缓存清理迟到响应、队列稳定性、渐变、复合进度条、搜索分页、大列表键盘、歌词与设置。

Windows 为本次实机验收平台。macOS 通过 Universal 云端构建验证编译与打包，未完成 Mac 实机播放、媒体键、设备切换和睡眠唤醒兼容性验收。Mac 安装包使用临时代码签名，不包含 Apple 公证。
