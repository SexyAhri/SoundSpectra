# 音乐库（1.1.13）

音乐库沿用现有工作台。Native Provider 管理认证和远程数据，共用播放器管理队列、缓存和状态；新增平台实现 `model.rs` 的 Provider 并注册登录流程及能力，不需要复制界面或播放引擎。

## 平台与登录

QQ 音乐独立实现账号、会员、创建 / 收藏歌单、全部分页、全站搜索、音质授权、封面及歌词。全站搜索使用 QQ 官方 `music.search.SearchCgiService / DoSearchForQQMusicDesktop`，携带当前登录会话；歌曲点播另行取得当前账号的播放授权。搜索与云端写入为可选能力，界面依据 Provider capabilities 显示。本版 QQ 全站搜索开放，云端收藏和歌单写入尚未经过真实写入与读回验收，隐藏入口；公共写入契约预留读回核验。

扫码页在隔离官方 WebView 内运行官方轮询与授权交换，工作台仅显示二维码和状态；额外验证由用户打开官方窗口完成。远程页面无应用 IPC 权限。Windows 凭据在配置目录 `music/qq-session.dpapi` 以当前用户 DPAPI 加密，官方 WebView 独立保存在 `music/qq-webview`。Cookie、签名音频地址不进入前端、SQLite、场景、导出与诊断。macOS 会话仅保留在进程内，尚无跨启动凭据恢复。

## 播放与错误恢复

`playback.rs` 是播放状态的唯一持有者；前端命令按接收顺序进入 Native，授权与音频请求在可取消后台任务内执行。加载期间可暂停、停止和连续上下首；具体歌曲点选以最后目标为准。过期歌曲代次和命令版本的响应无效，暂停意图不会被下载完成覆盖。后台 `music-player` 只持有 HTMLAudio 和受限的本地播放命令，切换工作台页面不影响音频。

自动选取账号实际可用的最高音质：超级会员候选依次包含臻品母带、臻品音质、臻品全景声、Hi-Res、SQ、HQ、标准 MP3、AAC；绿钻从 Hi-Res 开始，普通或过期账号从 HQ 开始。会员信息未知时仍由服务端授权决定；成长等级不等同于歌曲权限。资源不可用或解码失败逐级降级，不以试听绕过授权。FLAC 规格取自 STREAMINFO，MP3 / AAC 码率按文件长度和时长估算；实际音质显示在播放栏。

校验首段后立即播放，其余内容后台下载。Native 仅向隐藏播放器暴露带随机凭证的本机环回地址；校验 Host、路径和 Range，限制连接数，远距离跳转可另取服务器分段。无 Content-Length 的兼容路径有完整下载等待。单曲最多 256 MiB；半成品不落盘，切歌与停止取消旧请求。播放、下载、实际缓冲范围和跳转动画叠在同一进度条，下载完成隐藏纹理，减少动态效果时停用动画。200 毫秒淡出、250 毫秒淡入独立于用户音量，归零立即静音。

网络授权失败重试两次，等待一秒、三秒，可取消。传输中断恢复最多两次，持续成功播放后重置预算。登录失效停止自动重试并提供扫码入口；自动续播遇资源或解码不可用最多连续跳过三首。断网保留暂停现场，联网仅在目标及命令版本仍匹配时恢复；休眠间隔检测和输出设备错误会尝试从原进度恢复。设备兼容性由系统和 WebView 音频后端决定。

当前歌曲完整下载后才预取下一候选，最多 4 MiB 内存，不落缓存、不续期、不计入历史。随机候选提前确定，切歌只消费一次；更换队列、模式、账号或加载目标时取消旧预取。真正播放仍重新确认授权。系统媒体键、耳机与系统面板经 MediaSession 接入受限 Native 命令；外部音源激活时释放内置媒体状态。

## 持久化、搜索与队列

`music/library.sqlite` 按账号哈希隔离歌曲索引、歌单、播放现场、最近记录、偏好、浏览现场与歌词偏移。不保存 Cookie 或播放地址；保留 Native 点播所需歌曲标识。数据库迁移先生成一致备份，再在事务中升级，较新格式拒绝降级读取。

现场包含稳定队列条目标识、曲目、位置、音量、静音与模式。播放进度最多每五秒保存，暂停和正常退出立即保存；重启恢复后暂停等待操作。最近播放保留 1000 首去重记录，独立于音频清理。元数据后台逐页同步，分页按服务端跨度计算，被过滤的歌曲也占跨度；缺页不能标记同步完成。尚未同步的数据不在本地搜索结果中，可刷新读取更新的索引。

歌曲右键菜单提供立即播放、下一首播放、加入队列和封面重试。按歌名、歌手、专辑、时长排序，保留完整版本标题；点播沿用当前显示顺序。队列可拖动排序、用上下移按钮操作、多选移除及清除当前之前的歌曲，稳定条目标识保持正在播放的音频与进度；当前歌曲受保护。歌单、筛选、排序和滚动位置按账号恢复，长列表按需渲染；轮询使用队列版本，未变化时不重复克隆或发送完整队列。

## 缓存与响度

音频和歌词独立获取，保存在 `music/cache/track-*`。默认总容量 4 GiB，可选 1 / 2 / 4 / 8 GiB，最多 4096 曲；歌词单条 2 MiB，音频单曲 256 MiB。身份由平台、歌曲 ID、标题、歌手、专辑和时长决定。连续七天未播放同时移除音频和歌词，超限按最久未播放清理；启动、每小时、写入及容量调整时清理。只有实际播放续期，预取、查看和刷新歌词不续期。

设置可分别清理音频和歌词，正在使用的资源释放后补清理，清理前发出的迟到请求不能重新写回。缓存失败不阻止在线播放；损坏内容重新获取，刷新歌词失败保留有效版本。音频缓存仍需要当前账号在线授权，确认账号、音质、长度和内容校验后复用，不承诺离线播放。封面独立位于 `music/covers`，上限 128 MiB，七天未访问清理，失败可右键重试。

歌曲响度平衡默认关闭。完整缓存后，单个有队列上限的后台工作线程使用 Symphonia 逐包解码、ebur128 测量，避免完整 PCM 常驻内存。以 −18 LUFS 为目标，仅衰减过响歌曲，下一次播放生效；未分析、静音或无法解码时保持原音量。测量按缓存质量与内容校验值保存于歌曲的 `loudness.json`，不会附着到替换后的文件。依赖许可见 `THIRD_PARTY_NOTICES.md` 和 `licenses/`。

## 歌词与定时

逐曲偏移保存在 SQLite，范围前后十秒，每次 0.5 秒，正值延后。Native 只给副本应用一次逐曲偏移，全局偏移由公共显示规则另行合成；音乐库与桌面歌词一致，点击跳转使用相同偏移规则。歌词手动滚动后保持浏览状态，点击“回到当前句”继续跟随；制作信息不作为演唱歌词高亮。

睡眠设置支持 15 / 30 / 60 分钟及本曲结束暂停，经过现有淡出停止；不持久化睡眠倒计时。停止、清空和模式切换保持用户音量偏好。

## 诊断与验证

本地阶段日志保留最多 512 条，仅记录固定阶段、歌曲代次和结构化错误类别，不接受凭据或任意远程地址。可在音乐库设置导出 JSON；SQLite 写入失败也记录明确的存储类别。

自动检查入口为 `npm run check:full`，包含依赖、版本、发布脚本、前端、完整浏览器回归、Rustfmt、Rust 全测试与本机原生构建。音乐专项测试覆盖取消与最后目标、暂停交错、随机预取、账号隔离和恢复、迁移及缺页、历史上限、缓存清理迟到响应、队列稳定性、渐变、复合进度条、搜索分页、大列表键盘、歌词与设置。

Windows 为本次实机验收平台。macOS 通过 Universal 云端构建验证编译与打包，未完成 Mac 实机播放、媒体键、设备切换和睡眠唤醒兼容性验收。Mac 安装包使用临时代码签名，不包含 Apple 公证。
