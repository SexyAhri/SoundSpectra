# 演出编排、转场与音乐映射

入口：工作台 → 桌面预览顶部「演出编排」（场景收藏旁）。弹窗内，「时间编排」左侧管理演出与时间标记，中间绑定歌曲并预演，右侧编辑所选标记；窄窗口中先显示预演，再显示编辑项。「切换转场」设置默认转场路线与时长。可载入「回声航线」原创视觉编排，直接预演或编辑，无需先写 JSON。

当前场景的音乐映射位于右侧「区域灯效 → 外观 → 音乐响应」，仅支持相应形变的场景显示此项。

## 第一次使用时间编排

1. 在桌面预览顶部打开「演出编排」。可以先点「体验 36 秒原创编排」，再点「播放预演」看一遍；预演不会控制音乐播放器。
2. 自己编排时点左侧「新建演出」，展开「添加时间标记」，填写「新增位置（秒）」并点「新增标记」。右侧「这一刻切换到」选择实际灯效，「标记名称」只是便于识别的备注。比如 0 秒潮汐之结、15 秒层海、30 秒星尘航道。
3. 点左侧任意标记，预演会跳到该时刻；右侧可改时间、灯效和转场。展开「更新场景快照」可以复制当前区域或最新收藏的完整外观。修改自动保存。
4. 在播放器播放目标歌曲，点中间预演上方的「绑定当前曲目」，再点右下角「开启演出模式」。按钮不可用时，旁边会说明缺少歌曲、标记、可靠进度或作用区域。演出跟随歌曲进度，预演播放头仍只控制预演。

常规桌面窗口内，播放、回到开头和进度条位于画面下方，预演画面随可用高度缩放。演出名称、作用区域及导出、删除收在「演出设置」中；导入入口始终可见。

演出只控制指定区域；该区域需要在工作台显示，桌面效果也需要开启。结束时点「关闭演出」，回到工作台原有设置。

独立开发预演：`http://127.0.0.1:1420/tools/performance-lab.html`。

## 范围与存储

- 默认转场应用于手动灯效切换。收藏方案切换时，保留相同 ID 的区域独立转场；新增、删除、隐藏区域按原布局直接更新，暂未制作整张桌面的布局转场。
- 一个演出绑定一个指定区域，标记可以切换该区域的灯效快照、配色或启动一次运镜。全桌面的卡片、歌词、壁纸和区域位置不被标记替换。
- 场景标记保存视觉快照，附带可选收藏 ID 作为出处。改名和删除收藏不影响演出。取最新收藏时，优先取其中的同 ID 区域，缺少时取主区域。
- 配置单独保存在当前应用 WebView / 浏览器的 `soundspectra.performance.v1`，可用文件导入、导出。演出文件上限 1 MB、24 套演出，每套 200 个标记。导入先完整校验再应用；保存先持久化成功再发布状态。未修改原有设置及场景收藏的 Rust schema。
- 演出开启状态通过原生事件在工作台与桌面窗口间传递，进程内重建窗口可请求活动会话。开启状态不写入配置，重启应用不会自动开启演出。预演仅在自身上下文生效。

## 转场

| 路线 | 兼容范围 | 实际行为 |
| --- | --- | --- |
| 柔和交叠 | 所有三维灯效 | 冻结最后显示画面，准备目标场景，再在有界线性光空间中交叠 |
| 粒子散聚 | 潮汐之结、层海之间 | 原场景的实际粒子沿各自固定方向散开，目标粒子聚拢；同时交叠两者的画面 |
| 镜头穿越 | 回声廊道、星尘航道之间 | 原镜头沿自身视轴推进，目标镜头从前移位置返回自身构图；中间使用交叠 |

其他组合回退柔和交叠。快速重选目标时捕获当前已混合画面，取消原路线并交叠至最新目标；减少动态使用短交叠。seek 或迟开演出直接重建目标，不重演历史粒子或穿越动作。

一个画布始终只有一个活动场景。目标编译时保留最后画面，不保留两套活动几何或两套音频驱动。过渡图像为三个受画布像素预算限制的 RGBA8 目标；旧快照按需分配。输出采用平方根编码保留暗部精度，混合前解码；ACES tone mapping 与最终 sRGB 转换各执行一次。当前遮罩和歌词 focus 也限制旧快照，避免旧内容重新覆盖文字。resize 保留快照并拉伸至新尺寸；卸载释放目标、材质和几何。

目标初始化或编译失败时恢复上一成功场景，保留基础设置并显示说明；之后切其他灯效可继续工作。首次初始化或上下文丢失仍显示原有渲染错误，切换灯效可重新创建画布。

## 音乐映射

第一版只为确有对应几何的三套构图声明目标：

| 场景 | 路径弯曲 | 局部展开 |
| --- | --- | --- |
| 潮汐之结 | 经线扭转，最多 0.7 弧度 | 内外粒子层分离，最多 1.6 场景单位 |
| 层海 | 横向波面偏移，最多 1.8 单位 | 上下波面分离，最多 2.4 单位 |
| 回声廊道 | 各轨道错位弯曲，最多 1.8 单位 | 轨道的局部半径展开，最多 1.8 单位 |

「场景原有响应」「低频推动路径弯曲」「低频推动局部展开」可直接选择。高级项提供低/中/高频真实 band RMS、真实起音包络、目标、强度和线性/平方曲线。

RMS 使用已有六频段物理输入；三频段输入也能直接使用。只用固定的 0.22 显示上限限制几何幅度，没有额外 FFT、自动增益或积分累积。叠加在原有音乐运动上，静音、过期输入或减少动态时该附加形变归零。场景与区域分别保存预设，切回时恢复其选择。音乐每帧只写运行时 uniform，不写配置，不引发 React 更新。

独立预演为共享的合成分析补充明确的合成 band RMS；这些数据不会冒充真实采集。对照页并排显示同一输入和构图下的两种几何响应。

## 播放与恢复规则

- 播放器 position / duration 使用秒，复用卡片和歌词的可靠时钟，进入演出模型统一为毫秒。只有独立预演使用自己的可拖动时间，不向播放器发命令。
- 开启前需绑定当前录音。优先使用来源与 trackId；缺失时要求来源、歌名、歌手、专辑及有效时长组合。缺少足够身份时仅可预演。
- 切歌或播放器会话改变会关闭演出。时间暂时不可用、过期、媒体信息中断时撤掉覆盖；同一曲目的可靠时间回来后可继续恢复。
- 每帧按绝对时间查出当前状态，暂停保持时间，前后 seek、循环和小幅校正都重新求值，不依赖「只触发一次」的回调。同刻动作按列表顺序；场景标记重置其后配色与运镜上下文。
- 运镜为有时限的正弦平方包络；结束回到当前基础镜头。seek 到中途直接显示对应姿态，seek 到末尾不会重新播放。减少动态停用标记运镜。
- 演出覆盖与基础设置独立。演出中手动改某个视觉字段，该字段优先至下一个场景标记；music / view / atmosphere 内按具体字段追踪，不冻结其他子项。布局、歌词和音频输入照常使用最新基础设置。关闭演出不回写陈旧配置。
- 删除目标区域时不套用至主区域；面板标示区域缺失并禁止开启。关闭演出的按钮在时间不可用时仍可使用。

## 验证入口与限制

`tests/performance.spec.ts`、`tests/performance-placement.spec.ts` 覆盖绝对时间、同刻动作、seek、循环、暂停、减少动态、物理频段、导入拒绝、手动覆盖、过期时间/切歌、保存失败原子性、快速重选、目标编译失败恢复、线性交叠、当前遮罩与 GPU 资源释放。渲染准备及尺寸变更同时参考 `tests/scene-preparation.spec.ts`、`tests/scene-resize.spec.ts`、`tests/hdr-surface-boundaries.spec.ts`。

`scripts/capture-performance.mjs` 记录原创 36 秒编排、跳转恢复及映射对照，输出到忽略的 `artifacts/performance/`。这是无声合成音乐特征录像，不能代表真实采集或原生帧率。

### Windows 原生验证

`scripts/native-performance-smoke.mjs` 是需主动运行的原生联调入口，要求已播放真实歌曲且桌面输出已开启。它临时加入区域与演出，退出时清理自身数据并恢复原有显示开关和转场设置。默认检查真实输入、手动转场、暂停、连续标记及关闭恢复；`PERFORMANCE_REVIEW_EXIT=1` 配合 `PERFORMANCE_REVIEW_TRANSPORT=1` 专门检查不同场景间的关闭恢复。`PERFORMANCE_REVIEW_HOLD=1` 在连续标记后保留临时演出，供人工或 Computer Use 操作播放器；把 `artifacts/performance-native/active.json` 的 `regionId` 写入同目录 `release.txt` 后继续清理，最多等待 10 分钟。

`tests/native-scene-preparation.spec.ts` 检查 Windows 原生路径在 KHR 完成标记未返回时仍能完成场景切换与恢复。实机检查还应覆盖关闭卡片和歌词后的歌曲绑定、暂停、前后跳转、单曲循环、自然切歌，以及退出演出后的基础外观恢复。

原生脚本运行后生成 `artifacts/performance-native/` 报告；历史联调产物已清理，不保留旧耗时及通过数量作为当前验收结论。播放器未提供 seek / repeat 时需在其原界面验证。演出开启状态不持久化，重启后需主动开启；其他播放器、macOS 和长时间运行需分别验收。
