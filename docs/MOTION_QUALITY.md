# 灯效运动质量（2026-11-07）

从 R3F 整合最后四项检查完成后的共享工作区开始。没有撤销既有修改、提交或推送。起点保存于本机 `artifacts/motion-quality/baseline/src/`，用于同配置、同输入的连续 A/B。保留全部 11 个旧 ID、参数、场景格式；未新增持久化参数。

## 复现与原因

旧时间线用“最新包的采样时间 + 距其到达的时间”作为显示时间，每个包重新锚定。包延迟变化会使时间倒退，经典场景又把倒退当成路径重置。真实 QQ 音乐、1420 Tauri 开发版修复前 10 秒中，工作台捕获一次时钟倒退和一次水母相位归零；该段桌面层未发生，不能说每个窗口每次必现。时间点见 `native-before-live/report.json` 的 samples/draws。

旧插值在新包到达时，直接从“上一包最终值”开始下一段，即使该值尚未显示到。受控测试中仅相隔 0.002ms 的读取出现约 0.01279 的频段跳变。两项回归修复前均失败，见 `regression-before.log`。

卡顿另行测量：修复前工作台合成提交间隔 P95 57.5ms、最大 72.1ms，31 个间隔超过 50ms；桌面层同段 P95 21.8ms、最大 29.5ms。单次 R3F CPU 提交 P95 约 0.6/0.7ms。独立 Chromium trace 将长任务定位到 React scheduler；布局与三维提交不是该段 50ms 长任务的主要成本。CPU profile 可见重复构造效果控件、拾光绳及隐藏应用设置对话框。此记录不把 CPU 提交称为显示 FPS。

## 公共修复

- 捕获/本地时钟使用持续映射；显示游标只前进，通过有限速率校正偏差。频段、频谱、长音及显示强度从同一历史时间段插值；原始 RMS 与共享起音保留捕获语义，重复/乱序/旧源拒绝规则不变。
- 标称保留一个 hop 的插值余量；超出余量的延迟会等待捕获端点，不能保证一个 hop 的总延迟上限，不外推声音。起音单独消费。
- 经典效果的相位及惯性速度由 `SceneMotion` 保管；几何重建、重复绘制、速率编辑不重播路径。隐藏恢复、源重连只重置音频历史，保留空间路径；静音及减少动态效果停止运输。
- 为检查器、拾光绳层及应用设置对话框建立稳定 props/memo 边界，媒体位置轮询不再构造这些无关子树。实际参数、区域、歌词及拾光绳更新仍刷新控件。

## 连续证据与验证

`scripts/capture-motion-study.mjs` 对冻结基线/当前渲染器逐帧输入相同的合成特征、1024/48000 时钟、确定性排队抖动、种子、镜头及设置，输出 WebM、逐帧相位/事件曲线和配置。包含孤立击打、连续节奏、长音、频段变化、弱音、突停、完全静音及恢复。明确不是 PCM DSP；QQ 音乐另行实机观测。

自动检查针对时间倒退、包边界跳变、重复事件、路径重建、刷新率差异、静音停绘及资源释放；不把美观编造成数值通过线。后续反馈的复现、修正和本机证据如下。

## 后续反馈：音乐回应与参数

真实 QQ 音乐的 12 秒观测发现，旧的终身最小捕获/到达时钟偏移在设备时钟漂移后积累误差：事件时钟已领先最新采样约 4.7 秒，起音瞬态在画面消费前衰减到约 `1e-26`。现在用最近两秒内的最小到达偏移持续校准，同时限制事件时钟最多领先可用采样一个 hop；显示游标仍只前进。1% 持续时钟漂移回归修复前失败、修复后通过，真实输入复验恢复非零低、中、高频瞬态。两次真实播放片段不同，不作为相同 PCM 的幅度 A/B。

画面将固定尺度的感知能量、持续频段和短时起音分开，避免频段再次乘较小 RMS 而让动作消失。原始采集 RMS、频谱及源端起音检测不变。连续运输随音乐能量和长音变化；起音驱动伞体收缩、丝绸传播褶波、星云亮结、雪晶转动、羽枝弯曲、雨地面波纹、旋臂微光、花瓣褶波及航道节点。完全静音和减少动态效果保留停止运输的规则。

常规外观保留空间、光感、音乐参与度三个偏好及配色、场景模式；隐藏手动速度、响应模式与重复亮度/尺度控制，造型数量、大小、方向等放入“造型细节”。旧字段和保存格式继续兼容，旧速度值仍作为造型的基准速率，音乐负责实时变化；不改写用户原生设置。

## 后续反馈：黑块与落雨

- 水母口腕及丝绸：归一化法线和视线的点积可能因浮点误差超过一，掠射光的分数次幂因此产生 NaN。修正归一化边界和幂底范围。实际显卡、用户尺寸/参数下，各 240 帧序列修复前各有一帧异常，修复后 source 与全部活动 Bloom 目标均无无效或负值。
- 极光：细光幕的 MSAA 边缘辅助采样可外插出 UV 范围，指数衰减溢出与零遮罩相乘产生 NaN。先限定材料 UV 范围，平方项改显式乘法。AMD RX 6700 XT / ANGLE D3D11，600 帧加速相位与不同镜头/距离/构图压力序列，修复前第 306、340、452 帧异常，修复后全部有限。该压力序列是合成输入和加速相位，不是实时音乐录像。
- 落雨：新增真实起音落点时漏掉了 `uOnsetOrigin` 的 GLSL 声明，导致 shader 编译失败。补齐后显示、镜头、参数保存、静音及 HDR/MSAA 定向复验通过。

本机证据：`black-blocks-live-before/after`、`black-blocks-aurora-stress-before`、`black-blocks-aurora-bounded`、`music-response-before/clock-fixed`，均位于 `artifacts/motion-quality/`。`hdr-surface-boundaries.spec.ts` 覆盖近正视曲面法线及极光范围外辅助采样；`musical-scenes.spec.ts` 分别检查源 RMS、区域瞬态、冻结运输后的局部音乐回应、银河载体的实际像素覆盖及精简控制。

`final-review/index.html` 保存全部 11 种效果的 20 秒连续左右 A/B，各 601 个仿真帧，固定输入、种子、配置和镜头。包含骤停、静音及恢复，无页面异常，所有渲染器释放后几何/纹理计数为零。静态采样另汇总为四张 `review-sheet-*.png`。这些片段没有声音，不能代替真实音源听感或端到端延迟测量。

## 后续反馈：浮游、花境及最大化预览

晴空浮游改为有细纤维、弯曲羽枝和细长尾梗的三维羽絮，使用柔边窄带网格代替旧线段伞冠；不同深度、倾角和速度形成层次。持续音影响舒展和漂浮速度，起音只弯曲部分羽枝，高频点亮少数个体。沉浸模式保留低亮度天空层，日常模式透出壁纸。

星瓣花境改为三朵前后错落、各三层交错花瓣的花朵，带小颗粒花蕊和游离花瓣。曲面有杯形弧度、卷边、轻微瓣脉和材质明暗；深度写入减少原先透明瓣片混杂。长音舒展、起音局部褶波、高频花蕊/瓣尖微光分别响应，不以整朵放大代替节奏。旧效果 ID、保存参数、镜头和配色保持兼容；两张选择器缩略图同步用实际场景重绘。

最大化后只占四分之一的原因是 R3F 默认 `gl.setSize(..., true)` 把首次测得的像素尺寸写进 canvas 的内联 CSS，阻止其跟随父容器扩大。现在由父容器和百分比 CSS 决定显示尺寸，ResizeObserver 观察父容器；原失败回归从 320×180 放大至 640×360，修复后恢复全尺寸及四象限完整像素覆盖。

窗口尺寸事件合并 90ms 后更新 GPU 缓冲区，期间 CSS 填满预览。纯尺寸变化只更新现有 R3F store，不重复 configure/render 场景；尺寸与 DPR 原子更新，去掉 R3F 分别设置两者造成的重复清空/分配。自动缩放回归验证一轮扩大/缩小各只更新一次宽、高，同时保留几何、材质及后处理目标的标识，静音画面会重绘一次后恢复休眠。预览测量也跳过相同尺寸的 React 更新。

- `final/index.html`：日常/沉浸模式、同参数合成输入的静态前后对比；`final/preview.png` 为两个新造型的实际渲染。
- `continuous-final/index.html`：两个效果各 20 秒、601 个连续仿真帧的前后录像，包含鼓点、长音、高频、静音和恢复。无页面异常，释放后的几何/纹理均为零。这是合成特征重放，无声音，不是实际 PCM 或实时帧率测量。
